# Quick Textures – טקסטורות מהירות

מוד צד-לקוח ל-Minecraft **26.2** (Fabric) שמדליק ומכבה את חבילות המשאבים ("הטקסטורות שלי") בלחיצת מקש אחת.

## מה המוד עושה

מקש אחד – **J** כברירת מחדל (במקלדת עברית זה המקש **ח**):

| פעולה | מה קורה |
|---|---|
| **לחיצה קצרה** | מדליק או מכבה מיד את הטקסטורות שבחרתם. על שורת הפעולה מופיע "טקסטורות: דולק" או "טקסטורות: כבוי". |
| **לחיצה ארוכה** (חצי שנייה) | פותח תפריט עם כל חבילות המשאבים שמותקנות במשחק, ושם מסמנים אילו מהן הן "הטקסטורות שלי". |

- **הדלקה** מוסיפה את החבילות שבחרתם מעל החבילות האחרות שכבר דולקות, לפי הסדר שלהן בתפריט.
- **כיבוי** מסיר רק את החבילות שלכם. חבילות אחרות שהדלקתם בעצמכם לא נוגעים בהן.
- אם עוד לא בחרתם חבילות, לחיצה קצרה תציג: "לחיצה ארוכה על J כדי לבחור טקסטורות".
- המוד בודק בכל פעם מה **באמת** דולק במשחק, כך שגם אם שיניתם חבילות דרך התפריט הרגיל של המשחק, הכול נשאר מסונכרן.
- חבילה שנבחרה ונמחקה מהתיקייה פשוט מדולגת, בלי הודעות שגיאה.
- חבילה שנבנתה לגרסה אחרת של המשחק מסומנת בתפריט באזהרה ⚠, ותודלק בכל זאת (כמו ש"להדליק בכל זאת" עובד במשחק עצמו).
- המקש לא עושה כלום כשמסך אחר פתוח (צ'אט, מלאי, תפריט) או בזמן שהחבילות נטענות מחדש.

## התקנה

1. התקינו את **Fabric Loader** ל-Minecraft 26.2: מורידים את המתקין מ-<https://fabricmc.net/use/installer/>, בוחרים בגרסה 26.2 ולוחצים Install.
   צריך **Java 25** ומעלה (המשגר הרשמי של Minecraft כבר מביא אותה).
2. הורידו את **Fabric API** לגרסה 26.2 מ-[Modrinth](https://modrinth.com/mod/fabric-api) או מ-[CurseForge](https://www.curseforge.com/minecraft/mc-mods/fabric-api).
3. שימו את שני הקבצים בתיקיית `mods`:
   - `fabric-api-….jar`
   - `quicktextures-1.0.0.jar` (נמצא ב-`build/libs` אחרי בנייה, ראו למטה)

   איפה התיקייה `mods`?
   - Windows: `%appdata%\.minecraft\mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
4. במשגר בחרו בפרופיל **fabric-loader-26.2** והפעילו את המשחק.

## שימוש

1. שימו חבילות משאבים בתיקיית `resourcepacks` כרגיל.
2. בתוך עולם, **החזיקו J** חצי שנייה. ייפתח התפריט "בחירת הטקסטורות שלי".
3. סמנו ✔ את החבילות הרצויות ולחצו **סיום**. (**ביטול** או Esc סוגרים בלי לשמור.)
   אם הטקסטורות דולקות באותו רגע, השינוי ייכנס לתוקף מיד.
4. מעכשיו **לחיצה קצרה על J** מדליקה ומכבה אותן.

### החלפת המקש

אפשרויות ← שליטה ← צירופי מקשים ← קטגוריה **"טקסטורות מהירות"**.

### איפה נשמרת הבחירה

בקובץ `config/quicktextures.json` בתוך תיקיית המשחק. נשמרת בו רק רשימת החבילות, למשל:

```json
{
  "packs": [
    "file/MyPack.zip"
  ]
}
```

## למפתחים: בנייה

```bash
cd minecraft-mod
./gradlew build        # הקובץ נוצר ב-build/libs/quicktextures-1.0.0.jar
./gradlew runClient    # מפעיל את המשחק עם המוד לבדיקה
```

צריך JDK 25. הגרסאות מוגדרות ב-`gradle.properties` (נלקחו מ-fabric-example-mod ומ-fabric-api בענף 26.2):

| רכיב | גרסה |
|---|---|
| Minecraft | 26.2 |
| Fabric Loader | 0.20.1 |
| Fabric Loom | 1.19-SNAPSHOT (`net.fabricmc.fabric-loom`, בלי מיפויים כי המשחק לא מעורפל מגרסה 26.1) |
| Fabric API | 0.161.0+26.2 |
| Gradle | 9.8.2 |
| Java | 25 |

מבנה הקוד (`src/main/java/com/kesefhacham/quicktextures`):

- `QuickTexturesClient` – רישום המקש וזיהוי לחיצה קצרה או ארוכה בכל tick.
- `TextureToggler` – הדלקה וכיבוי: עדכון `PackRepository`, ‏`options.resourcePacks`, שמירה וטעינה מחדש.
- `PackPickerScreen` – התפריט עם הרשימה הנגללת.
- `PackIcons` – טעינת `pack.png` של כל חבילה.
- `QuickTexturesConfig` – קריאה ושמירה של `config/quicktextures.json`.
